    Pip-Boy

    Apps

    Install opens the app on the Pip-Boy’s APPS menu: the dashboard copies it over, adds the menu entry on the SD card and, if Storage is full, offers to make room first.

    Extensions for the stock interface

    Extensions add screens to the Pip-Boy’s own interface instead of replacing it, and start each time it does. Holding the torch button while the Pip-Boy starts skips them. A Pip-OS update removes them; install them again afterwards.

    The extension loader on your Pip-Boy has an update (it now scrolls the menu names when extensions add more than fit).

    Install your own app

    Choose a JavaScript file written for the Pip-Boy. It’s installed the same way: copied to Storage and added to the APPS menu.

    Files

    Storage is the Pip-Boy’s built-in memory, holding its firmware, apps and settings. The SD card holds music, videos and other media.

    Copies over USB run at about 3 KB/s and are checked as they go. For large videos or music a card reader is much faster.

    Pip-Boy

    Backup & restore

    Keep copies of the Pip-Boy’s Storage on this computer and put them back with one click.

    Storage backups

    A backup holds every file in Storage: the firmware, apps and settings (not the SD card). It’s downloaded and also kept here.

    Free up space

    When you delete or update files, the Pip-Boy keeps using their space until Storage is rewritten. This backs up everything, erases Storage, writes the files back and restarts the Pip-Boy, all in one go (about two minutes).

    Complete copy

    FOR THE EMULATOR

    Copies the whole Pip-Boy (device details, every Storage file and the SD card) into data/dumps/, so the emulator can run an exact copy. It can take a while; an interrupted copy can be resumed.

    Options

    Larger files are listed in the copy’s manifest so you can copy them from the card with a reader.

    Companion data

    Your radio presets, settings profile and app notes from this dashboard. Restoring adds them to what you have (presets you already have are skipped) and is all-or-nothing.

    Connection

    DISCONNECTED

    Low-memory safe mode: standby

    If connecting fails
    Make sure no other program (such as the Espruino IDE) or browser tab has the port open, and that the Pip-Boy is on with its screen awake. Unplug and re-plug the cable, then press Connect. Recover console interrupts a program that’s stuck; Test connection only checks the Pip-Boy answers.

    For automation

    Live state for scripts and agents driving this page. The dashboard talks to the Pip-Boy’s Espruino console over USB (Web Serial) only: no Wi-Fi, Bluetooth or cloud. One command runs at a time; every task records one outcome below.

    Outcomes: verified, unavailable, timeout, failed, cancelled, disconnected, uncertain-write (stop and inspect before retrying), low-memory-safe-mode (reconnect before retrying). Erasing, restoring, overwriting and deleting always ask first.
