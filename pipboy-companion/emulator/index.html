“Run in RAM” resets the interpreter first, then types the program into the REPL.
          “Save as boot code” stores it in Storage as .bootcde, which runs at every boot (on a loaded
          dump that replaces the device's firmware until you load the dump again). “Save to Storage & load()” keeps the
          boot code and runs the file instead, from flash, as load("app.js") does on the device.

      


      

        
Device dump

        
A dump made on the dashboard's Full Mode page: its Storage goes into flash, its SD card files onto the emulated card.

        

          
          
        

        

        
Apps

        
Apps from the project's apps/ folder. Installing writes the app to Storage and runs it with load(); the device's firmware stays in place (on the Pip-Boy app, the power button returns to it).
